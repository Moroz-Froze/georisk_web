# Оползни — устойчивость склонов для QGIS 4

Самостоятельный плагин для предварительной оценки зарождения неглубоких оползней по статической модели бесконечного склона. Устанавливается отдельно от плагина лавин и не зависит от него. Проверен в QGIS 4.2.1 / Qt 6.11.

## Установка и запуск

1. В QGIS откройте **Модули → Управление и установка модулей → Установить из ZIP**.
2. Выберите `landslide_scenario-0.1.0.zip`, установите и включите **Оползни — устойчивость склонов**.
3. Откройте **Модули → Оползни — устойчивость склонов → Оползни · устойчивость склонов** или нажмите значок склона.
4. Добавьте OpenStreetMap, перейдите к координатам и выделите участок прямоугольником.
5. Нажмите **Загрузить реальный рельеф выделенного участка**. Учебные данные не нужны. По умолчанию используется публичный Copernicus GLO-30, без API-ключа и регистрации. Нужен интернет.
6. Во вкладке **Грунт и вода** задайте обоснованные параметры или подключите зоны изысканий. При отсутствии данных числа в интерфейсе можно использовать только как сценарные допущения.
7. При необходимости добавьте ось ЖД. Нажмите **Рассчитать устойчивость**, затем **Открыть отчёт**.

Можно сразу запустить расчёт: реальный рельеф будет загружен в начале. Собственная детальная ЦМР выбирается в режиме **Свой файл рельефа**. Для неизменного участка, буфера и сетки уже загруженный растр используется повторно. Сетевые ошибки не подменяются синтетическим рельефом.

## Метод

Используется равновесие слоя по эффективной прочности Мора–Кулона:

`FS = [c + c_root + (gamma*z*cos(beta)^2 - u)*tan(phi)] / [gamma*z*sin(beta)*cos(beta)]`

`u = m*9.81*z*cos(beta)^2`

Глубина `z` — **вертикальная**, в метрах; сцепление — кПа; удельный вес — кН/м³; углы — градусы. `m` — отношение вертикальной высоты воды в слое к его глубине, от 0 до 1. Это не содержание влаги в грунте или дождь. Одинаковый удельный вес используется при сравнении всех состояний.

Метод сверён с уравнением (1), §2.2, печатная с.5 [руководства SINMAP (Pack, Tarboton, Goodwin)](https://hydrology.usu.edu/sinmap/sinmap.PDF). Реализован детерминированный баланс, без гидрологической части и индекса SI из SINMAP. Дополнительно изучены [USGS TRIGRS](https://www.usgs.gov/software/trigrs) для дождевой инфильтрации и [USGS Scoops3D](https://www.usgs.gov/software/scoops3d) для объёмных поверхностей разрушения. Эти решатели в плагин не включены.

## Результаты

- Коэффициент устойчивости FS: без положительного водного напора, при заданном `m`, при полном обводнении.
- Критическое `m` для FS=1. Значения ниже 0 и выше 1 сохраняются: это случаи, когда граница находится вне рассматриваемого диапазона. При нулевом трении водный порог не определён.
- Карта пользовательских классов устойчивости; классы пологих, слишком крутых и неизвестных участков отделены.
- Поровое давление и фактические карты исходных параметров `input_*.tif`.
- При заданной оси ЖД — длина её непосредственного пересечения с зонами и минимальный FS в коридоре.
- GeoTIFF, GeoPackage, HTML-отчёт и JSON со всеми параметрами, геометрией и источниками.

`FS < 1` — неустойчивость в сценарии. `FS ≥ 1` не доказывает безопасность. По умолчанию анализируются уклоны 5–60°, граница отображения большего запаса — 1.3. Эти настраиваемые пороги не являются проектными нормативами ЖД. Пологая площадка не получает автоматического заключения об отсутствии опасности.

## Полигональные зоны грунта

Можно использовать один набор параметров либо полигональный слой с числовыми полями:

| Поле | Содержание |
|---|---|
| `c_kpa` | Эффективное сцепление грунта, кПа |
| `root_kpa` | Добавочное корневое сцепление, кПа; 0 при отсутствии |
| `phi_deg` | Эффективный угол внутреннего трения, градусы |
| `gamma_knm3` | Удельный вес грунта, кН/м³ |
| `depth_m` | Вертикальная глубина поверхности скольжения, м |
| `m_ratio` | Высота воды в слое / его глубина, 0–1 |

Зоны должны покрывать все анализируемые склоны в выделении и буфере. Перекрытия и пробелы останавливают расчёт; единые значения в пробелы не подставляются. У полей должны быть обоснованные источники: изыскания и наблюдения. Глобальные почвенные карты не заменяют испытаний на прочность.

## Ограничения

Цель — планирование инженерных изысканий, не окончательное обоснование строительства. Модель не описывает глубокие оползни, круглоцилиндрические поверхности, обвалы, разжижение, движение и дальность схода, изменение давления после дождя, сейсмику, подрезку и выемки, защитные сооружения, нагрузку и вибрацию поездов. Не рассчитываются денежный и индивидуальный годовой риск. Пересечение оси ЖД с зоной срыва не равно прогнозу попадания оползня с вышележащего склона.

Copernicus — модель поверхности с шагом около 30 м, а не детальная модель грунтовой поверхности. В неё входят растительность и сооружения. Для откосов и проектных решений нужны своя детальная ЦМР, геологические разрезы, прочностные испытания, гидрогеологические наблюдения и проверка специалистами. Численная проверка выполнена; калибровка по реальным оползням не выполнена.

NoData сохраняется как неизвестная область. Риск за пределами покрытия не приравнивается к нулю. Для растра FS непосчитанные ячейки — NoData=-9999, для классов — 255. Ограничение расчёта — 2 млн ячеек. Все результаты сохраняются в отдельной новой папке запуска.

## Данные и проверка

Источники: [Copernicus DEM](https://registry.opendata.aws/copernicus-dem/), [структура и лицензия](https://copernicus-dem-30m.s3.amazonaws.com/readme.html), [OpenStreetMap](https://www.openstreetmap.org/copyright) только для навигации. Ссылки на научные источники также включены в справку и отчёт.

Проверка из корня проекта:

```powershell
& 'C:\Program Files\QGIS 4.2.1\bin\python-qgis.bat' tools/verify_landslide.py
```

Проверяются аналитические пределы без сцепления, вертикальная глубина и размерности давления, водный порог FS=1, порядок трёх сценариев, NoData, пологие/крутые участки, некорректные данные, неоднородные зоны и их покрытие, пересечение с ЖД, отмена, реальный API Processing, интерфейс Qt 6, настоящая загрузка Copernicus и расчёт на загруженном рельефе через кнопки плагина. Синтетические плоскости используются только для тестов.

Processing: `landslide_scenario:infinite_slope`. Требуемый вход — `AREA`, один полигон; `DEM`, `SOIL`, `RAIL` необязательны. Архив собирается `tools/package_landslide.py`. Дополнительные пакеты через pip не нужны.
