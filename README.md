# ГеоРиск — FastAPI + React

Единое веб-приложение для трёх существующих моделей: лавины, оползни и лесные пожары. Карта MapLibre на весь экран, выдвижная панель слева, инструменты карты снизу. Выделение прямоугольника, загрузка реального Copernicus GLO-30, сценарные параметры, фоновые задания, отмена, история, карты с легендами и непрозрачностью, HTML-отчёты и ZIP с GeoTIFF / GeoPackage / JSON / CSV. Интерфейс на русском, адаптируется к узкому экрану. Учебные данные в рабочем интерфейсе не используются.

## Запуск на этом компьютере

Дважды щёлкните `webapp/start.cmd`. Откройте **http://127.0.0.1:8000**. Для остановки нажмите Ctrl+C в окне сервера. Здесь зависимости и интерфейс уже подготовлены.

На другом Windows-компьютере нужны Node.js 22+ и Python с NumPy/GDAL. Скрипт автоматически находит Python из установленного QGIS в Program Files и при первом запуске устанавливает веб-зависимости только в `webapp/.deps`. Десктоп QGIS запускать не нужно: сервер использует GDAL/NumPy, а не QGIS API. Нестандартный путь:

```powershell
.\webapp\start.ps1 -QgisPython 'C:\Program Files\QGIS 4.2.1\bin\python-qgis.bat' -Port 8000
```

## Запуск без установленного QGIS

В корне проекта:

```sh
docker compose up --build -d
```

Открыть **http://localhost:8000**. Контейнер устанавливает системный GDAL и NumPy. Результаты сохраняются в постоянном томе `georisk-data`. Локальная сборка Docker в текущей Windows-среде может быть недоступна; проверенный способ здесь — `start.cmd`.

## Работа

1. Откройте меню ☰ слева вверху, выберите модель. Найдите участок по карте или введите **долготу, широту** и нажмите стрелку.
2. Нажмите «Выделить участок» в меню либо кнопку прямоугольника в нижней панели: два клика задают противоположные углы. Escape отменяет действие. Широта поддерживается от −80 до 80°. Буфер учитывает соседние склоны.
3. Проверьте параметры. Для оползней свойства грунта и обводнение задаются вами. Для пожара выберите дату, тип горючего и, при необходимости, точку зажигания.
4. Нажмите «Рассчитать участок». При сетевой ошибке выводится причина; искусственные высоты и погода не подставляются.
5. Результаты и выбор слоёв находятся во вкладке «Результат» левой панели; кнопка слоёв снизу открывает эту вкладку. Здесь можно сравнить показатели, открыть отчёт или скачать архив. История хранится на сервере, включая ошибки и отменённые задания. Нижняя панель также содержит перемещение, масштаб +/−, показ участка, сброс поворота на север, очистку и полный экран.

Copernicus GLO-30, Sentinel-2 через Earth Search и модельная погода Open-Meteo загружаются без ключа. Доступность, лимиты и условия этих сервисов остаются внешними зависимостями. NDVI/NDMI не преобразуются в вероятность пожара. Без очага пожарная модель рассчитывает потенциальную интенсивность, а не распространение.

## Свои данные

- Одноканальный GeoTIFF высот в метрах с системой координат, до 200 МБ.
- Ось ЖД: GeoJSON LineString/MultiLineString, WGS 84, координаты `[долгота, широта]`.
- Грунтовые зоны: GeoJSON Polygon/MultiPolygon с числовыми полями `c_kpa`, `root_kpa`, `phi_deg`, `gamma_knm3`, `depth_m`, `m_ratio`. Требуется полное покрытие анализируемых склонов без перекрытий.
- Лавинные очаги: GeoJSON Polygon/MultiPolygon. При отсутствии используется поиск склонов по настраиваемым порогам.
- Горючее: GeoJSON Polygon/MultiPolygon с полем `fuel`: C2, C3, D1, O1A, O1B, S1, NF или WA. Без Sentinel-2 этот файл обязателен. Пробелы остаются неизвестными.
- Метеоряд: CSV UTF-8, запятая, поля `date,temp_c,rh_pct,wind_kmh,wind_from_deg,rain_mm`; ежедневная последовательность до даты сценария. Полуденные значения местного стандартного времени, ветер 10 м, осадки за предыдущие 24 часа. GeoJSON и CSV — до 10 МБ.

Собственные файлы имеют приоритет над сетевыми источниками. Свойства грунта, повторяемость лавины, стоимость восстановления, тип горючего и его строение автоматически из рельефа не определяются.

## Архитектура и API

- `backend/main.py`: FastAPI, типизированная проверка запросов, загрузка файлов, выдача результатов.
- `backend/jobs.py`, `worker.py`: последовательная очередь и отдельный процесс на расчёт. До 8 активных/ожидающих заданий. Один серверный процесс (`workers=1`). Лимит одного расчёта 30 минут. При перезапуске незавершённые задания помечаются прерванными.
- `backend/inputs.py`: преобразование веб-входов в конфигурации существующих моделей.
- `backend/exports.py`: геопривязанные PNG-превью и переносимые архивы. PNG для браузера уменьшаются до 1200 пикселей по длинной стороне; научные GeoTIFF сохраняют исходную сетку. Прозрачные пиксели — неизвестно или не отображаются; это не нулевой риск.
- `frontend/`: React 19, TypeScript, Vite, MapLibre GL JS. После сборки интерфейс отдаёт сам FastAPI; отдельный сервер Node в рабочем режиме не нужен. Для карты требуется WebGL.
- Расчётные модули `avalanche_scenario`, `landslide_scenario`, `wildfire_scenario` используются напрямую. Формулы не дублируются.
- `webapp/data`: загрузки, задания, результаты, журналы. Путь меняется переменной `HAZARD_DATA_DIR`. Сервер слушает `127.0.0.1:8000`, порт — `PORT`, адрес — `HOST`.

API: `/api/health`, `/api/catalog`, `POST /api/uploads`, `POST /api/jobs`, `GET /api/jobs`, `GET /api/jobs/{id}`, `POST /api/jobs/{id}/cancel`, файлы и ZIP. Интерактивная документация: **http://127.0.0.1:8000/docs**. Документация стеков: [FastAPI](https://fastapi.tiangolo.com/), [React](https://react.dev/), [Vite](https://vite.dev/guide/), [MapLibre](https://maplibre.org/maplibre-gl-js/docs/).

Локальная версия предназначена для одного исследователя или доверенной рабочей группы. Авторизация и разделение пользовательских данных не включены. Для публикации в интернете нужны аутентификация, HTTPS, квоты хранения и отдельная инфраструктура очереди. Не запускайте несколько Uvicorn workers на одной папке данных.

## Разработка и проверки

```powershell
& 'C:\Program Files\QGIS 4.2.1\bin\python-qgis.bat' -m pip install --target webapp/.deps -r webapp/requirements-dev.txt --no-cache-dir
& 'C:\Program Files\QGIS 4.2.1\bin\python-qgis.bat' -X utf8 webapp/run.py --test
cd webapp/frontend
npm ci
npm run build
```

Для разработки интерфейса: `npm run dev`; Vite перенаправляет `/api` на FastAPI:8000. Интеграционные тесты используют синтетический рельеф исключительно как проверочный материал и выполняют все три настоящих расчётных workflow в дочерних процессах, проверяют коэффициент FS, PNG, отчёт и ZIP. Нужны GDAL, NumPy и Python 3.11+.

## Модели и границы

Лавины — огибающая независимых трассеров Фёлльми при заданной высоте потока; не полный RAMMS/SPH. Оползни — статическое равновесие бесконечного склона, без моделирования дальности схода. Пожары — классические FWI 1987 и FBP 1992 с сеточным распространением. Калибровка по наблюдаемым событиям региона не выполнена. Значения по умолчанию — сценарные допущения, а не свойства выделенного участка. Результаты не заменяют инженерные изыскания и не подтверждают безопасность строительства.

Все исходные ограничения и ссылки сохраняются в отчётах моделей. Пожарный модуль включает GPL-2.0 код CFFDRS: лицензия и точная ревизия сохранены в `wildfire_scenario/LICENSE` и `wildfire_scenario/third_party/cffdrs/UPSTREAM.md`. При распространении сохраняйте исходный код и уведомления об авторах. Условия Copernicus, Sentinel и OpenStreetMap также сохраняются.
