# Проверка Linux/Docker · 1.5.0 · 20.11.2026

Поставка рассчитана на будущий публичный адрес: origin, разрешённые Host, необязательный префикс и доверенный прокси задаются в `.env`. Домен для локальной проверки не требуется.

## Выполненные проверки

- Полный набор серверных проверок исходников: **92 passed**, 44,63 с. Запускался в изолированной Python/GDAL-среде Windows. Включены проверки упаковки, произвольного будущего HTTPS-домена, корня/подпапки, сессий, CSRF и выгрузки результатов. Единственное предупреждение — устаревающий интерфейс httpx в тестовом клиенте Starlette.
- Чистый Linux ZIP распакован в отдельную папку. **Из его содержимого действительно собран и запущен Linux/amd64-образ** в Docker Desktop с Linux Engine 29.8.0 / Compose 5.5.1. Установка зависимостей, `pip check` и контейнерный healthcheck завершились успешно.
- Фактическая среда образа: **Python 3.13.5, GDAL 3.10.3, NumPy 2.2.4, FastAPI 0.163.1**. База — Debian trixie-slim; Windows DLL, QGIS и Node.js в контейнере не используются.
- Оба примера проверены настоящим Nginx командой `nginx -t`. Через Nginx с TLS выполнены все три модели **в корне сайта и в `/georisk/`**: всего шесть завершённых расчётов. TLS-сертификат тестового localhost проверялся клиентом с отдельным доверенным тестовым CA; отключение проверки сертификата не использовалось.
- Для каждого расчёта проверены PNG, HTML, ZIP и GeoPackage: сигнатуры, наличие ожидаемых векторных слоёв и систем координат, совпадение GeoPackage внутри ZIP и при отдельном скачивании. Для оползневой модели дополнительно проверено контрольное значение коэффициента устойчивости.
- Проверены Secure-cookie с корректным Path, передача CSRF, отказ в доступе к чужому расчёту из второй сессии, завершение обеих сессий и отказ в доступе после выхода. Заголовок карты `Referrer-Policy: strict-origin-when-cross-origin` сохранён.
- Проверены реальные настройки запущенного контейнера: UID/GID **10001:10001**, read-only корень, сброс capabilities, `no-new-privileges`, PID-лимит 128, init и `restart: unless-stopped`. Квота CPU — **0.5 ядра**, RAM — **2 147 483 648 байт**, MemorySwap равен Memory; GDAL-кэш — **67 108 864 байта**. Это ограничения, а не замер потребления на больших участках.

Итоговый ZIP проверяется на CRC, отсутствие повторов, совпадение каждого файла с исходником и совпадение входов Docker-образа с реально проверенным комплектом. Расчётные библиотеки и готовый интерфейс побайтно сверяются с поставкой 1.4.1. В архив не входят приватные данные/настройки, сертификаты, Windows/IIS, CMD/PowerShell, тестовые данные и среда разработки.

## Границы проверки

Контейнер проверен локально на Linux Engine Docker Desktop; доступ к будущему серверу не предоставлялся. Реальные DNS, публичный TLS, IP доверенного прокси, автозапуск Docker после перезагрузки сервера и доступ к внешним поставщикам данных проверяет администратор при размещении.

Для повторяемости шесть интеграционных расчётов использовали небольшие синтетические растры, горючее и погоду из тестов. Они не входят в поставку; пользовательский интерфейс продолжает поддерживать загрузку реальных данных. Эти проверки не подтверждают научную точность прогноза, доступность всех внешних сервисов или достаточность 2 ГиБ для любого участка. Нагрузочный тест на целевых данных и обновление системных библиотек остаются задачами эксплуатации. Предыдущие замечания к нативным HDF4/netCDF не считаются исправленными одной сменой образа.
